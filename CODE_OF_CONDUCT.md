# Code of Conduct

Be kind, be constructive, assume good intent. Harassment is not tolerated.

All RhythmShahriar projects follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Reporting

Report unacceptable behavior privately to the maintainer, Rhythm Shahriar, at **me@rhy.io**.
Every report is reviewed and handled confidentially. The reporter's privacy is respected.
Enforcement follows the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
